## 第 1 页：GP315 四段校正（原理说明）

以 GP315 Iout 输出为例，对芯片进行归一化之后，芯片的输出**小于标准值**。

四段校正将 PWM 输入范围分为四段，每段使用不同的校准参数；校准后使用**补偿后的 PWM 替代当前 PWM**，补偿芯片输出，从而**减小输出误差并改善线性度**。

## 第 2 页：校准函数

原文提示：PDF 中可直接选中下面的函数代码进行复制使用。

```c
/*
 * PWM输入0~25mA输出模式PWM占空比补偿函数
 * 输入：0~1 （代表0.0%~100.0%）
 * 输出：0~1 （补偿后的值）
 *
 * 使用说明：直接把你的占空比传进来，拿返回值去设PWM占空比就行
 */
double PWM_to_Current_Processor(double duty_in)
{
    double k1 = 0.0036, k2 = 0.0021, k3 = 0.0027, k4 = 0.0030;
    double duty_out = 0;

    // 防止输入超范围
    if (duty_in < 0) duty_in = 0;
    if (duty_in > 1) duty_in = 1;

    // 分成四段补偿
    if (duty_in <= 0.25)
        duty_out = (duty_in - 0) * (1 + k1);
    else if ((0.25 < duty_in) && (duty_in <= 0.50))
        duty_out = (duty_in - 0) * (1 + k1) - (duty_in - 0.25) * k2;
    else if ((0.50 < duty_in) && (duty_in <= 0.75))
        duty_out = (duty_in - 0) * (1 + k1) - (duty_in - 0.25) * k2 - (duty_in - 0.50) * k3;
    else
        duty_out = (duty_in - 0) * (1 + k1) - (duty_in - 0.25) * k2 - (duty_in - 0.50) * k3 - (duty_in - 0.75) * k4;

    // 防止输出超范围
    if (duty_out < 0) duty_out = 0;
    if (duty_out > 1) duty_out = 1;

    return duty_out;
}
```

系数：k1 = 0.0036，k2 = 0.0021，k3 = 0.0027，k4 = 0.0030。

## 全文关键信息一页摘要（AI 摘要，非原文）

- **对象**：GP315 芯片，PWM 输入、0~25mA 电流输出（Iout）模式
- **问题**：归一化后芯片输出小于标准值，最差偏小 35µA，线性度最差 0.14%
- **方案**：MCU 侧分段线性预补偿——把 PWM 输入范围按 25%/50%/75% 分为四段，用补偿后的占空比替代原始占空比下发
- **实现**：单个 C 函数 `PWM_to_Current_Processor()`，输入/输出均为 0~1 的占空比，四个系数 k1~k4，累积式写法保证段间连续
- **效果**：误差 35µA → ±3µA；线性度 0.14% → 0.015%
