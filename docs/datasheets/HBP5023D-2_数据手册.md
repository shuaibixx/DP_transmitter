## I2C 通讯协议
I2C总线使用SCL和SDA作为信号线，这两根线都通过上拉电阻（典型值4.7KΩ）连
接到Vddio，这样使得空闲状态都保持为高电平。A7~A1位组成从机的地址，W/R位是数
据传送方向位，0表示主机向从机写数据，1表示主机由从机读数据，如表3所示。
**表3：I2C地址**

A7 A6 A5 A4 A3 A2 A1 W/R
1 1 0 1 1 0 1 0/1
**表4：内部寄存器信息**

读取数据按照如下指令顺序进行操作：
1. 读取0xA5寄存器值，将读取到的二进制值“与”上“11111101”后再写入0xA5。
2. 发送指令0x0A到0x30寄存器进行一次温度采集，一次压力数据采集。
3. 读取0x30寄存器地址，若Sco位为0代表采集结束，可以读取数据，或等待延迟10ms
（10ms适用于OSR_P范围在256X~4096X）。
4. 读取0x06、0x07、0x08三个寄存器地址数据构成24位AD值（压力数据AD值）。
5. 将读取到的24位AD值进行如下操作计算出最终压力输出：OUT(Pa)=AD/2^23*Fullscal。
注意Fullscal的取值：
eg：当满量程压力为600000Pa时，2^19<600000<2^20,在24位AD中最少需要20位来
表示，即此时Fullscal取2^20。
电路内部寄存器请参考如上表4。
其中REG0x06、REG0x07、REG0x08寄存器内为压力输出值共计24位，其中最高位
为符号位，符号位数值为“1”时代表“负”，符号位数值为“0”时代表“正”。REG0x09、REG0x0A
寄存器内为温度输出数值共计16位，其中最高位为符号位，符号位数值为“1”时代表“负”，符
号位数值为“0”时代表“正”。I²C通讯时序值如表5所示。

### I²C时序
> 图2：参考电路I²C通讯时序图

图2是参考电路I2C的时序图。从设备应答后，主设备继续发送8位寄存器地址，得到
应答后继续发送或读取数据。SCL处于高电平，SDA发生一个上升沿动作标志I2C通信结
束。除了开始和结束标志之外，当SCL为高时SDA传输的数据必须保持稳定。当SCL为
低时SDA传输的值可以改变。I2C通信中的所有数据传输以8位为基本单位，每8位数据
传输之后需要一位应答信号以保持继续传输。
### I²C 协议数据传输
在启动条件下Start(S)，SCL是高电平时候，SDA由高电平到低电平的变化，代表开
始。在停止条件下Stop(P)，SCL依然为高电平时候，SDA由低电平到高电平变化，代表
停止。起始和终止信号都是由主机发出，起始信号产生后，总线处于被占用状态，在终止信
号产生后，总线就处于空闲状态，如图3所示。

### hbp5023d.c

`c
#include "hbp5023d.h"
#include "iic2.h"
#include "math.h"

/**
 * @brief  HBP5023D 初始化
 * @note   I2C2_Init() 需要在 main 中提前调用
 *         此处可添加传感器特殊配置（如OSR、工作模式等）
 */
void HBP5023D_Init(void)
{
    // I2C2 初始化已在 main 里完成
    // 默认配置即可正常工作，如需修改 OSR 等参数请在此处添加
}

/**
 * @brief  启动一次采集并读取原始数据 (5字节)
 * @param  buf: 输出缓冲区，至少5字节
 *              buf[0] = 压力高8位 (REG0x06)
 *              buf[1] = 压力中8位 (REG0x07)
 *              buf[2] = 压力低8位 (REG0x08)
 *              buf[3] = 温度高8位 (REG0x09)
 *              buf[4] = 温度低8位 (REG0x0A)
 * @return 1 = 成功, 0 = 失败
 *
 * 操作流程 (参考 HBP5023D 手册):
 * 1. 读 0xA5，与 0xFD (11111101) 后写回，清零 bit1
 * 2. 写 0x0A 到 0x30，启动一次温压采集
 * 3. 读 0x30，等待 SCO 位变为 0 (采集完成)
 * 4. 从 0x06 开始连续读 5 字节 (压力3字节 + 温度2字节)
 */
uint8_t HBP5023D_ReadRaw(uint8_t *buf)
{
    uint8_t  reg_val;
    uint16_t timeout = 0;

    // ---- 第1步: 配置 0xA5 寄存器 ----
    // 读 0xA5，将 bit1 清零后写回
    if (I2C2_DevRead(&reg_val, 0xA5, 1, HBP5023D_ADDR) == 0)
    {
        return 0;
    }
    reg_val &= 0xFD;   // 清零 bit1 (即 11111101)
    if (I2C2_DevWrite(&reg_val, 0xA5, 1, HBP5023D_ADDR) == 0)
    {
        return 0;
    }

    // ---- 第2步: 启动采集 ----
    // 写 0x0A 到 0x30，启动一次温度+压力采集
    reg_val = 0x0A;
    if (I2C2_DevWrite(&reg_val, 0x30, 1, HBP5023D_ADDR) == 0)
    {
        return 0;
    }

    // ---- 第3步: 等待采集完成 ----
    // 轮询 0x30 寄存器，SCO 位为 0 表示采集结束
    // 超时保护：OSR=4096 时约 10ms，留余量
    do
    {
        if (I2C2_DevRead(&reg_val, 0x30, 1, HBP5023D_ADDR) == 0)
        {
            return 0;
        }
        timeout++;
        if (timeout > 500)   // 约 500 次 I2C 读操作，超时退出
        {
            return 0;
        }
    } while ((reg_val & HBP5023D_SCO_BIT) == HBP5023D_SCO_BIT);

    // ---- 第4步: 读取数据 ----
    // 从 0x06 开始连续读 5 字节
    // REG0x06~0x08: 24位压力值 (最高位为符号位)
    // REG0x09~0x0A: 16位温度值 (最高位为符号位)
    if (I2C2_DevRead(buf, 0x06, 5, HBP5023D_ADDR) == 0)
    {
        return 0;
    }

    return 1;
}

/**
 * @brief  获取压力和温度的物理值
 * @param  pressure:     输出压力值 (单位: Pa，与 fullscale_pa 同量纲)
 * @param  temperature:  输出温度值 (单位: °C)
 * @param  fullscale_pa: 满量程压力值 (单位: Pa)
 *                       例: 量程 -100~+200kPa → fullscale = 300000 Pa
 * @return 1 = 成功, 0 = 失败
 *
 * 计算公式:
 * - 压力: P = AD_press / 2^n   (n 为满量程对应的移位系数)
 * - 温度: T = AD_temp / 256.0  (°C)
 *
 * 满量程 n 值的确定方法：
 *   找到满足  2^(23-n) < FullScale < 2^(24-n)  的 n 值
 *   即 FullScale 在 24 位 AD 中需要多少位来表示
 *
 *   例: FullScale = 600000 Pa
 *       2^19 = 524288,  2^20 = 1048576
 *       600000 在 2^19 ~ 2^20 之间
 *       所以 n = 3 (23 - 20 = 3)
 */
uint8_t HBP5023D_GetData(float *pressure, float *temperature, int32_t fullscale_pa)
{
    uint8_t  buf[5] = {0};
    int32_t  press_adc;
    int16_t  temp_adc;
    int32_t  fullscale;
    int8_t   n;

    // 读取原始数据
    if (HBP5023D_ReadRaw(buf) == 0)
    {
        return 0;
    }

    // ===== 压力值计算 =====
    // 拼接 24 位有符号整数：
    // buf[0] 是高8位，buf[1] 是中8位，buf[2] 是低8位
    // 先左移8位到 int32 的高24位，再算术右移8位保留符号
    press_adc  = (int32_t)buf[0] << 16;
    press_adc |= (int32_t)buf[1] << 8;
    press_adc |= (int32_t)buf[2];
    press_adc  = press_adc << 8;   // 移到最高位
    press_adc >>= 8;               // 算术右移，保留符号位

    // 计算满量程对应的 n 值
    fullscale = fullscale_pa;
    n = 0;
    for (int8_t i = 0; i < 24; i++)
    {
        if ((fullscale > pow(2, 23 - (i + 1))) && (fullscale < pow(2, 23 - i)))
        {
            n = i;
            break;
        }
    }

    // 压力 = AD 值 / 2^n
    *pressure = (float)press_adc / pow(2, n);

    // ===== 温度值计算 =====
    // 拼接 16 位有符号整数
    temp_adc = (int16_t)(((int16_t)buf[3] << 8) | (int16_t)buf[4]);

    // 温度 = AD 值 / 256.0  (°C)
    *temperature = (float)temp_adc / 256.0f;

    return 1;
}

### main.c 调用示例

在串口命令解析中增加一个命令（例如 x03）来读取 HBP5023D：

`c
else if(USART_FRAME.USART_FRAME_BUF[3] == 0x03)
{
    float   press = 0.0f;
    float   temp  = 0.0f;
    int32_t fullscale_pa;

    // 从串口命令获取满量程

                             (int16_t)USART_FRAME.USART_FRAME_BUF[5]) * 1000;

    if (HBP5023D_GetData(&press, &temp, fullscale_pa))
    {
        // 输出压力(kPa) 和 温度(°C)

    }

### 注意事项

1. **I2C 地址格式**：I2C2_DevRead/Write 的 addr 参数传的是 **8位写地址**（即7位地址左移1位）。HBP5023D 的7位地址是 x6B，所以传 xD6。如果发现通信不上，试试把地址改成 x6B。

2. **SCO 位位置**：代码中假设 SCO 位是 **bit1**（x02）。请以数据手册的寄存器表为准，如果不对，修改 HBP5023D_SCO_BIT 宏即可。

3. **超时处理**：轮询等待采集完成时加了超时保护（500次），防止传感器异常导致死循环。正常采集只需几毫秒。

4. **备选方案**：如果轮询 SCO 位不稳定，可以改用固定延时 10ms 代替：
   `c
   // 替代第3步的轮询，直接延时等待
   Delay(10);  // 延时约 10ms
   `

5. **量程计算**：代码中 ullscale_pa 是满量程值（不是测量范围的上限）。
   - 量程 -100 ~ +200 kPa → 满量程 = 300 kPa = 300000 Pa
   - 量程 -5 ~ +5 kPa → 满量程 = 10 kPa = 10000 Pa
