## 1. 与旧款 HBP5023D-1 的差异（**完全不兼容**）

项目最初按 -1 写驱动，2026-10-16 换成了 -2，**驱动重写**。

| 项 | HBP5023D-1（旧） | **HBP5023D-2（现用）** |
|---|---|---|
| 7bit 地址 | 0x78 | **0x6D** |
| 协议 | 发 `0xAC` 命令 | **读/写寄存器** |
| 读出 | 6 字节（status + 3B 桥 + 2B 温度） | 寄存器 `0x06~0x0A` |
| 忙判断 | 状态字 Bit5 | `0x30` 寄存器 bit3 (SCO，0x08) |
| 压力换算 | `(MAX-MIN)/(90%AD-10%AD)×(raw-10%AD)+MIN` | `P = AD/2^23 × Fullscal` |
| 温度换算 | `(150+40)×raw/65536-40` | `T = AD/256` |
| 供电 | **1.8~3.6V** | **1.8~5.5V（典型 5.0V）** |

## 4. 寄存器与读取流程

### 寄存器表

| 寄存器 | 用途 |
|---|---|
| **0xA5** | 配置寄存器。读出来 `& 0xFD`（清 bit1）再写回 |
| **0x30** | 启动转换 + 状态。写 `0x0A` 启动一次温压采集；读它看 **bit3 (SCO，0x08)** |
| **0x06 / 0x07 / 0x08** | 压力 AD，24 bit **有符号**（最高位是符号位） |
| **0x09 / 0x0A** | 温度 AD，16 bit **有符号** |

> 用户已提供表4截图：CMD寄存器0x30的SCO为bit3，Measurement_ctrl为bits2:0。当前掩码0x08；读到0x02不表示忙。0xA5的配置清bit1与SCO不是同一寄存器位。

### 读取流程（手册原文步骤）

1. 读 **0xA5**，将值 `& 0xFD`（`11111101`，清 bit1）后写回 **0xA5**
2. 向 **0x30** 写 **0x0A** → 启动一次温度采集 + 压力采集
3. 读 **0x30**：**SCO 位为 0** 表示采集结束；**或者直接等 10 ms**
   （10 ms 适用于 OSR_P 在 256X~4096X）
4. 从 **0x06** 连读 5 字节：`0x06/0x07/0x08` 压力，`0x09/0x0A` 温度
5. 按下节公式换算

### 当前实现（`hbp5023.c` 的 `HBP5023_Read`）

严格按上面 4 步，但第 3 步做了兜底：

```c
/* 轮询 SCO 最多 HBP5023_SCO_POLL_TIMEOUT_MS = 50ms
   还不清 → 置 sco_stuck=1 → Delay_ms(10) → 直接往下读 */
```

原因见本文第 7 节。

## 5. 换算公式

### 压力

```
OUT(Pa) = AD / 2^23 × Fullscal
```

`Fullscal` = **覆盖量程跨度的最小 2 的幂**。

等价写法（更好算）：设 `2^k = Fullscal`，则

```
压力(Pa) = AD / 2^(23-k)
```

**本工程0～2.5kPa，跨度2500Pa**：Fullscal取覆盖跨度的2次幂4096Pa，k=12，压力(Pa)=AD/2^(23-12)=AD/2048。

手册的例子（跨度 600000 Pa）：`2^19 < 600000 < 2^20` ⇒ `Fullscal = 2^20` ⇒ `AD / 8` ✅ 自洽。

**符号处理**：24 bit 值 `m`，若 **bit23 = 1** 则为负数，`m -= 2^24`。

```c
press_adc = (raw[0]<<16) | (raw[1]<<8) | raw[2];
if (press_adc & 0x00800000) press_adc -= 0x01000000;
```

### 温度

```
T(°C) = AD_temp / 256
```

16 bit 有符号，直接按 `int16_t` 解释即可（`0x1900 = 6400 → 25.00 °C`）。

### 分辨力

```
当前换算步长 = Fullscal / 2^23
Fullscal=4096Pa ⇒ 约0.000488Pa/count（换算步长，不等同实际测量精度）
```

## 7. 当前验证状态（2026-10-22）

地址0x6D已应答，连续原始温压数据读取成功；SCO位误判已修正，0x30=0x02表示SCO清除。历史约0.15kPa及26～29℃日志只说明读取有数据，不等于零点或精度已校准。标准压力源校验、零点和满量程验证仍待完成。当前运行GP315独立测试，不采集传感器。

早期SCO卡住的经过见调试记录；不要恢复bit1忙判断，也不要恢复旧300kPa跨度。
