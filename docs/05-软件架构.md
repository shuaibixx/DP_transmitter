# 软件架构

> 2026-10-29：main.h仅集中传感器量程、固定标定目标和两点实测值。当前main.c已恢复温压采集与电流联动，屏幕代码保持删除。APP_GP315_CAL_CURRENT_MA=0启用压力联动，正值启用固定电流标定，当前状态以00-当前项目进度.md为准。

当前版本已移除历史测试模式（2026-10-27）。不再通过APP_SENSOR_TEST_ONLY、APP_OLED_TEST_ONLY、APP_GP315_TEST_ONLY切换测试。现仅由固定目标电流宏选择压力联动或固定电流标定。

## 正常流程

1. 使用内部HSI 8MHz，关闭PLL，初始化延时和串口。
2. 初始化GP315，压力联动模式首次有效采样前输出4mA目标；初始化传感器。
3. 读取温压，将0～20kPa线性映射为4～20mA，超出范围时限幅。
4. 按同一次采样更新GP315 PWM，并通过串口报告压力、温度、设定电流。
5. 串口输出AD、P（六位小数）、T、Iset，每轮末尾等待300ms；实际周期包含采集和串口打印耗时。

通信失败时，串口首次提示SENSOR ERROR，继续尝试采集；保持最近的电流输出，恢复后自动更新。SCO轮询与原有延时兜底策略保持一致。

## 配置入口

- User/Inc/main.h：传感器/应用压力量程、电流范围、采样等待时间、固定标定目标电流、GP315两点实测值。
- User/Inc/gp315.h：PA4硬件定义、PWM频率、基础占空比、参考电流、标定开关、状态及驱动API；两点实测值通过main.h引入。
- User/Inc/soft_i2c.h：48MHz参考延时30循环，初始化按当前时钟缩放；8MHz为5循环，使用直接GPIO寄存器操作。
- 工程编译宏：SYSCLK_FREQ=8000000、SYSCLK_SRC=SYSCLK_USE_HSI；与main.c的内部8MHz初始化一致。

0～25mA是GP315未标定换算及厂家补偿的基础模式；本应用工作范围仍是4～20mA。串口Iset是设定值，不是电流反馈。厂家double补偿函数保留原样，字库和芯片标准库保留。
