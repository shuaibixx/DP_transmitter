# 03 — GP315 PWM转电流输出

## 当前两点标定版本（2026-10-26）

8000计数版本未加板级校准时，用户五档实测为4.033、8.034、12.031、16.028、20.031mA。现已按4.033/20.031两点估算标定占空比，在GP315_SetCurrent_mA中对目标电流直接插值占空比，保持厂家PWM_to_Current_Processor原函数及8MHz、1kHz、8000计数不变。

校准使能和占空比在gp315.h：GP315_CAL_ENABLE=1，GP315_CAL_4MA_DUTY_PCT=15.867984%，GP315_CAL_20MA_DUTY_PCT=79.875984%，均为厂家补偿前百分数。中间电流按两端占空比线性插值，再进入厂家原函数，不再先修正毫安指令。端点由上轮两点读数估算，可直接调节宏并实测微调。直接设置原始或补偿前占空比的两个API不经过板级校准；正常毫安接口及独立五档测试经过校准。重新采集基准数据前需先关闭本校准，避免重复修正。

量化后五档比较值预计1274、2557、3839、5118、6396，分母8000。按25mA跨度和原实测估算，电流约4.002、8.000、12.000、15.997、20.000mA；这些是计算估计，不能当作校准后的实测验收结果。

编译日志gp315_duty_calibration_build.log：0错误、0警告，Code=13806、RO=326、RW=16、ZI=1024；厂家函数与应用说明去除空白/注释后仍完全一致。下一步烧录后复测五档，记录温度、稳定时间和万用表读数。本文后续旧阶段“尚未标定”及占空比记录仅反映当时状态。

更新日期：2026-10-27。当前进度及完整实测记录见[项目进度](00-当前项目进度.md)。芯片资料保存在 `datasheets/GP315_数据手册_V1.23.md` 和 `datasheets/GP315_四段校正应用说明.md`；本文说明当前工程实现，不把软件换算初值当作实测传递关系。

## 1. 当前输出链路

```text
目标电流mA
  → GP315_SetCurrent_mA：I/25×100，得到补偿前百分数
  → GP315_SetOutputPercent：百分数/100
  → PWM_to_Current_Processor(double)：厂家原四段函数，输入输出0～1
  → 返回值×100，送入gp315_write_duty
  → 比较值向下取整，写TIM3->CCDAT1
  → PA4输出PWM → GP315产生环路电流
```

厂家函数类型double、公式、限幅和系数保持原样。四段系数为0.0036、0.0021、0.0027、0.0030，分界为25%、50%、75%。函数优化线性度，不读取实际电流，也不自动校准4/20mA绝对值。厂家要求外部万用表标定两点；板级两点修正已接入，见本文开头当前版本说明。

## 2. 两组范围不能混用

| 配置 | 当前值 | 用途 |
|---|---|---|
| main.h：APP_CURRENT_MIN/MAX_MA | 4 / 20mA | 正常模式压力上下限对应电流 |
| gp315.h：GP315_CURRENT_MIN/MAX_MA | 0 / 25mA | 电流换算成占空比的初始范围 |
| gp315.h：GP315_DUTY_MIN/MAX_PCT | 0 / 100% | 补偿前占空比端点 |

0～25mA映射0～100%是当前按用户要求采用的标定初值，不保证硬件实际可输出0mA。旧版0.5～25mA映射1～100%的配置已撤销。不能为了工作范围4～20mA，就把驱动换算端点也设为4/20而占空比仍铺满0～100%。

当前五档统一正常换算，补偿前4/8/12/16/20mA对应16/32/48/64/80%。实际电流需万用表验证。

## 3. 当前整机模式及历史独立测试

当前APP_GP315_TEST_ONLY=0、APP_GP315_ENABLE=1，已联动压力读取和OLED：0～2.5kPa映射4～20mA，超量程限幅。启动等待数据时设置4mA目标，读取失败保持上一电流并显示错误。历史独立测试的4/8/12/16/20mA每10秒循环仅在重新开启独立测试宏时运行。最近两点实测4.003/19.999mA来自独立测试，整机带显示负载后的低端仍需复测。

2026-10-26已取消第一档10%的临时试测覆盖，五档统一调用GP315_SetCurrent_mA。4mA补偿前16%、补偿后16.0576%、计数1284/8000、实际16.05%。串口target current=4.00mA为目标，不是电流反馈。旧10%实验仅作历史证据保留。

若检查固定原始PWM，可设 `APP_GP315_TEST_RAW_PWM=1`，由 `APP_GP315_TEST_DUTY_PCT` 设置，跳过补偿。此宏当前为0。不要把原始PWM实验与带补偿的标定数据混用。

## 4. 定时器和诊断

- PA4，TIM3_CH1，AF2；`GP315_USE_TIM1_CH1=0`。用户已反馈PWM波形正常，无证据需要切换TIM1。
- 当前8MHz试测版本：HSI直供、PLL关闭，内核及定时器时钟8MHz，PSC=0，计数8MHz，ARR=7999，仍输出1kHz。GP315_TIMER_CLK_HZ引用SystemCoreClock，前提为APB不分频；8MHz版本尚待上板复测。历史4MHz版本PSC=3、48MHz版本PSC=47。
- 8000个计数，占空比分辨率0.0125个百分点；比较值取整向下。0%常低、100%常高。
- `GP315_GetRawDutyPercent()` 返回补偿后、量化前请求值；实际占空比为CCDAT1/8000。
- `PWM diag`只读采样CNT及PA4电平：CEN=1、CC1E=1、OC1M=6、PA4_mode=2、AF=2为预期配置。中间档读到高低电平支持引脚翻转；窄脉冲可能漏采，不能据PA4_high=0就认定没有PWM。
- 软件没有电流反馈。打印目标值和比较值不能证明环路电流正确。

低端占空比16%降到10%后仍约6.55mA，用户确认PWM波形正确，支持存在低端电流下限，但根因未确认。不要把6.55mA当作正常4mA端点直接做线性标定。

下一步先确认整板供电来源和电流表串接位置；断电后断开OLED供电，再上电复测低端。若无改善，再结合实际原理图查外围、电阻、外接晶体管及回流路径。独立测试不初始化OLED不等于断开OLED耗电。整板耗电限制只是待验证假设，尚无隔离测量结果。

## 6. 硬件资料边界

工程资料记录PWM频率50Hz～50kHz，高电平2.7～5.5V，环路供电8～30V，内部5V输出最大带载10mA。能否用其给MCU等负载供电，必须核对实际电路及低端电流预算；10mA带载能力不表示两线环路在4mA时可供10mA。当前供电关系未确认，不据此认定硬件故障。
