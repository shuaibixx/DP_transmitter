## 当前数据链路

```text
传感器24位有符号压力输出AD
  → P(Pa)=AD/256，P(kPa)=AD/256000（仅适用于当前0～20kPa配置）
  → Iset(mA)=4+P(kPa)×0.8，电流目标限幅4～20mA
  → 板级两点标定后的补偿前占空比插值
  → 厂家PWM_to_Current_Processor(double)四段补偿原函数
  → TIM3比较值／PA4 PWM
  → GP315及外围输出环路电流（外部万用表实测）
```

当前跨度20000Pa，换算满刻度取32768Pa，得到256计数/Pa。温度为有符号温度AD/256°C。AD是传感器寄存器提供的数字输出，不等同于器件内部补偿前ADC。

压力不作应用零点扣减、跨度校正、滤波或限幅；只对电流目标限幅。负压力仍打印负值，电流目标最低为4mA。六位压力小数不代表六位测量精度。Iset是软件设定值，没有环路电流反馈测量。

客户按当前量程反算：`P(kPa)=(实测电流(mA)-4)/16×20`。通用式为`P=Pmin+(I-4)/16×(Pmax-Pmin)`。

## 常改参数与标定

`code/N32G031_DP_transmitter/User/Inc/main.h`当前值：

```c
#define SENSOR_PRESSURE_MIN_KPA (0.0f)
#define SENSOR_PRESSURE_MAX_KPA (20.0f)
#define GP315_CAL_MEASURED_LOW_MA  (3.980f)
#define GP315_CAL_MEASURED_HIGH_MA (19.970f)
#define APP_GP315_CAL_CURRENT_MA (0.0f)
#define APP_SAMPLE_PERIOD_MS (300u)
```

- 固定电流宏为0：采集压力并输出电流；设为4.0f或20.0f：固定该目标mA，不初始化、读取传感器。
- 两个实测宏任意一个为0：跳过整组自动端点计算，使用基础占空比。它不控制传感器是否采集，也不会自动测量电流。
- 每次启动在GP315_Init中计算一次并缓存，不写入Flash；相同代码和宏重复烧录不会叠加修正。
- gp315.h保留基础补偿前端点15.867984%／79.875984%、参考电流4／20mA、CAL_ENABLE=1、AUTO_ENABLE=1。3.980／19.970mA是与这组基础端点配对的固定电流基准数据。
- 厂家double原函数及四段系数0.0036／0.0021／0.0027／0.0030保持原样；0～25mA是芯片基础换算范围，整机工作输出仍为4～20mA。

新板／重新标定的完整步骤见[GP315宏标定](08-GP315宏标定.md)。压力联动时测得的电流不能直接替换固定4／20mA基准宏；自动修正后的复测值也不能与旧基础端点直接重新配对。

## 已解决问题与保留行为

- 低端约6.55mA的平台现象在用户降低主频后恢复正常；当前保持8MHz，未独立量测确认耗电／回流的完整根因。
- 软件I²C参考30循环@48MHz，按主频缩放，8MHz为5循环，并保留直接GPIO寄存器操作。此配置已成功读取；不能退回8MHz下固定30循环或早期固定5µs实验。
- SCO忙位采用CMD 0x30的bit3／0x08；0x02不能按bit1误判为转换忙。
- 启动等待首个有效压力时设定4mA；读取失败时保持最近输出、首次打印错误，恢复后继续更新。故障电流策略尚未定义，保持输出不代表故障期间压力有效。
- 主循环末尾等待300ms，实际周期还包含采集和串口耗时；用户日志约0.33s/次。
