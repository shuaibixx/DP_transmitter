# GP315宏标定

> 2026-10-30：源码的固定电流基准宏仍为3.980／19.970mA。最近两轮压力联动实测见[09记录](09-压力与电流实测记录.md)，没有据此改写宏。压力驱动时Iset未必恰为4／20mA，不能把这些电流直接作为固定电流基准；重新采集前按下述步骤将实测宏置零。

常改参数在`code/N32G031_DP_transmitter/User/Inc/main.h`：传感器量程、固定标定目标电流、两点实测电流。基础占空比、PWM频率与标定开关仍在`User/Inc/gp315.h`，通常不用改。当前APP_GP315_CAL_CURRENT_MA=0.0f，主程序默认采集压力并转换为电流；将该宏改为正值可固定输出做电流标定。

## 使用步骤

1. 新板先将下面两个实测电流宏都写为`0.0f`。任意一个为0，都会跳过整组两点计算，使用基础占空比；这不是将零代入公式。

   ```c
   #define GP315_CAL_MEASURED_LOW_MA  (0.0f)
   #define GP315_CAL_MEASURED_HIGH_MA (0.0f)
   ```

2. 保持`GP315_CAL_ENABLE=1`。在main.h将`APP_GP315_CAL_CURRENT_MA`设为`4.0f`，编译烧录，用万用表测量并记录；再改成`20.0f`编译烧录，测量高端。这两次测量必须使用同一组基础占空比和相同硬件、时钟、PWM频率。

3. 将这两个实测值填回宏，单位为mA。例如当前板已测得：

   ```c
   #define GP315_CAL_AUTO_ENABLE      (1)
   #define GP315_CAL_MEASURED_LOW_MA  (3.980f)
   #define GP315_CAL_MEASURED_HIGH_MA (19.970f)
   ```

4. 重新编译烧录。GP315_Init中计算一次修正端点并缓存，SetCurrent接口随后使用缓存端点插值，不在每次输出时重复反算。串口打印自动标定状态和实际采用的补偿前占空比端点。

5. 分别固定4、20mA复测，再检查8、12、16mA。标定结果是估算，需万用表验证。完成后将main.h中的APP_GP315_CAL_CURRENT_MA改回0.0f，重新编译烧录即可恢复压力联动，无需替换main.c。

## 基础端点与开关（gp315.h，通常不用改）

```c
#define GP315_CAL_4MA_DUTY_PCT    (15.867984f)
#define GP315_CAL_20MA_DUTY_PCT   (79.875984f)
```

基础端点必须与采集实测值时使用的占空比相对应。不要把自动计算的端点写回这里后继续沿用旧实测值，否则会重复修正。当前3.980/19.970mA对应上面这组基础值。

`GP315_CAL_AUTO_ENABLE=0`同样跳过自动计算，不论实测宏填写多少，都直接使用基础端点。它不会保留上一次自动算出的结果。若只想用手动标定端点，关闭AUTO后将手动端点填入基础宏。

`GP315_CAL_ENABLE=0`则关闭整个板级端点标定，恢复0～25mA基础换算，仍经过厂家补偿函数；采集本流程的基准数据时应保持它为1。

实测宏非零但顺序错误、数据超出支持范围或修正无法由PWM表示时，串口提示Invalid calibration data，并退回基础端点。实测宏为0属于未填写，不报告无效。没有电流反馈采样，填写0不会触发自动测量。

## 计算方式

先将基础端点经过厂家补偿与实际PWM量化，得到两次测量对应的比较值C1、C2。对于目标电流I：

```text
C(I) = C1 + (I - 实测低端电流) × (C2 - C1)
            ÷ (实测高端电流 - 实测低端电流)
```

目标比较值就近取整，再反求厂家补偿函数输入，取对应计数区间中点以避免浮点量化跳到相邻计数。厂家原函数保持不变。

当前8MHz、1kHz PWM每周期8000计数。基础比较值为1274/6396，填入3.980/19.970mA时预计修正到1280/6406，反算端点约15.948834%/80.004770%。这是计算预期，不是万用表复测结果。六位小数不代表电流有六位小数精度。

不要将自动修正后的复测电流，直接填到仍对应旧基础占空比的测量宏中。需要重新采集基准时，先把实测宏设0，再测两端。
